# OpenSourceify 2.0

OpenSourceify 2.0 is an enhanced platform where you can post your projects and allow others to contribute to them. It also features a learning page where users can learn different programming languages like JavaScript and C++.

This new version brings better UI, improved readability, and expanded learning options. We have also migrated our backend from MongoDB to **Supabase**.

## New Features in 2.0

- **Project Chat:** Users can now chat discussion threads on shared projects.
- **Project Stories:** Share the story and motivation behind your project.
- **Upvoting System:** Upvote projects you find interesting or useful.
- **GitHub Profile Integration:** Share your GitHub profile directly on the platform.
- **Better Learning Resources:** Enhanced learning page with better options.
- **Modern UI:** A complete redesign for better aesthetics and readability.


## Installation

### Prerequisites

- Node.js
- npm
- TypeScript

### Backend Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/NIYAZ04/openSourceify
   cd openSourceify/backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the backend server:
   ```bash
   npm run dev
   ```

### Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd ../frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the frontend server:
   ```bash
   npm run dev
   ```

# Contributions
Contributions are welcome! Please follow these guidelines to contribute:

### How to Contribute
1. Fork the repository on GitHub.

2. Clone your forked repository to your local machine:
   ```bash
   git clone https://github.com/NIYAZ04/openSourceify.git
   cd openSourceify
   ```

3. Create a new branch from main with a name that reflects your GitHub username or the feature you're working on:
   ```bash
   git checkout -b username/feature-name
   ```

4. Make your changes, and ensure your code follows the project's coding style and conventions.

5. Test your changes if applicable.

6. **Update Developers.tsx with details of your contribution (important)**

7. Commit your changes with a descriptive commit message:
   ```bash
   git commit -am "Add your descriptive commit message here"
   ```

8. Push your changes to your forked repository:
   ```bash
   git push origin username/feature-name
   ```

9. Submit a pull request to the main branch of the original repository.

Code Style
Follow existing code style and naming conventions.

Use meaningful variable and function names.

Document complex or non-obvious parts of your code.

Use comments to explain your logic when necessary.

For security reasons, ensure all dependencies are kept up to date and implement proper access controls.
